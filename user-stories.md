# Brew Crew Today User Stories

## MVP

- As a Brewers fan, I want to choose a date so I can see whether the Brewers are playing that day.
- As a Brewers fan, I want to see the opponent so I know who the Brewers are playing.
- As a Brewers fan, I want to see whether the game is home or away and the venue so I know where it is being played.
- As a Brewers fan, I want to see the scheduled first pitch time so I know when to tune in.

## Later

- As a Brewers fan, I want a shortcut to the next Brewers game so I can skip date hunting.
- As a Brewers fan, I want a calendar-style schedule view so I can scan upcoming games quickly.
- As a Brewers fan, I want TV and radio broadcast information so I know where to watch or listen.
- As a Brewers fan, I want probable pitchers so I can get a better sense of the matchup.
- As a Brewers fan, I want live score and game status after first pitch so the app stays useful during the game.
- As a baseball fan, I want to save a favorite team so this checker can work for more than just the Brewers later.
