# Brew Crew Today

A tiny Brewers schedule checker. Pick a date and the app tells you whether the Milwaukee Brewers are playing, who they are playing, where the game is, and the scheduled first pitch time.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Data source

The app uses the public MLB Stats API schedule endpoint for the Milwaukee Brewers team ID `158`.
